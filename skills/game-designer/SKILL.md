# 游戏设计师

> 将你的灵感火花变成可落地执行的游戏设计方案。

## 能力

- **一句话生成完整设计**：输入游戏概念 → 输出组件、规则、胜负条件、变体策略
- **设计模式识别**：引擎构建、push your luck、区域控制、工人放置等经典模式自动匹配
- **多类型支持**：桌游、派对游戏、社交游戏、数字游戏、小游戏
- **原型就绪**：输出内容可直接用于原型开发，不需要二次翻译

## 使用方式

```
/game-designer "一个让玩家体验散户在大A股市场生存的肉鸽卡牌游戏"
```

## 工作流

1. 描述你的游戏核心概念（一句话足够）
2. AI 生成完整设计方案（核心循环、机制、规则、变体）
3. 审视方案，标注想保留/修改的部分
4. 迭代优化，直到满足预期
5. 输出到 GDD 阶段继续细化

## 输出示例

```
核心循环：抽牌→出牌→结算→市场波动→下一轮
胜利条件：在12轮熊市中保持净资产为正
失败条件：爆仓/融资爆仓/心态崩溃
核心机制：恐惧指数、纪律值、FOMO卡牌效果
变体：牛市模式、震荡市模式、期货杠杆模式
```

## 设计原则

- 小游戏优先——2 周可出 MVP
- 创意自带传播——梗/情绪/真实经历即营销
- 机制驱动——不是卖美术，是卖玩法

## 适用场景

- 独立游戏创意萌芽阶段
- Game Jam 快速出方案
- 从模糊想法到可讨论的设计文档
- 一人团队需要外部设计视角

## 限制

- 不生成美术资产，只出文字方案
- 不做市场分析（交给 indie-hacker-strategy）
- 不做技术可行性评估（交给 game-developer）

# GDD 生成器

> 把一份游戏点子变成发行商看得懂、程序员能实现的设计文档。

## 能力

- **完整 GDD 生成**：概览 → 核心循环 → 机制系统 → 角色故事 → 关卡框架 → 技术需求 → 制作路线图
- **系统设计器**：经济系统、战斗系统、进度系统、社交系统、商业化模型
- **关卡与世界设计**：布局原则、难度曲线、世界观构建、节奏控制
- **叙事设计**：三幕结构、英雄之旅、分支对话
- **按游戏类型专项**：RPG / FPS / 策略 / 手游 / Roguelike 各有专项模板

## 使用方式

```
/gdd-generator
```

然后提供 game-designer 的输出或你的游戏设计概要。

## 工作流

1. 输入游戏概念（来自 game-designer 或直接描述）
2. 选择游戏类型（RPG / 策略 / 休闲 / Roguelike...）
3. AI 按模板生成完整 GDD
4. 逐章节审查和修改
5. 导出为 Markdown，存入项目仓库

## GDD 结构

```
# 游戏名称
## 1. 游戏概览（一句话定位、目标受众、平台、核心卖点）
## 2. 核心循环（玩家每分钟/每回合在做什么）
## 3. 机制系统（规则、数值模型、经济循环）
## 4. 角色与故事（如果有）
## 5. 关卡设计（布局、难度曲线、节奏）
## 6. 技术需求（引擎、平台、性能目标）
## 7. 制作路线图（MVP→迭代→完整版）
```

## 适用场景

- 独立开发者需要向发行商/投资人 pitch
- 单人开发时需要书面化设计以理清思路
- 多人协作时需要统一设计语言

## 限制

- 不做市场分析
- 不做竞品调研
- 不做技术选型推荐（交给 game-developer）

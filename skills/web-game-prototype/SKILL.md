# Web 游戏原型机

> 想验证玩法？一句话让浏览器跑起你的游戏原型。

## 能力

- **自然语言 → Three.js 游戏**：描述游戏玩法和视角，直接生成可运行原型
- **多类型支持**：FPS、第三人称、RPG、塔防、平台跳跃、宝可梦风格
- **迭代模式**：可以不断请求修改、新功能、角色和机制
- **相机自适应**：按游戏类型自动选择最佳相机方案
- **进度追踪**：自动维护 progress.md

## 使用方式

```
/web-game-prototype "做一个俯视角的太空射击游戏，玩家用键盘移动，鼠标射击，敌人从上方不断出现"
```

## 工作流

1. 描述游戏核心玩法（视角、操作方式、胜负条件）
2. AI 生成基础原型（单屏可玩）
3. 试玩 → 发现问题 → 反馈修改
4. 迭代直到玩法验证通过
5. 原型通过后，再决定用正式引擎重做

## 为什么要先做原型

- 2 天内验证核心玩法是否好玩
- 不需要装引擎，浏览器就能跑
- 失败成本极低——不好玩直接放弃，不用心疼
- 通过了的原型可以直接作为"可玩规格书"给程序员

## 适用场景

- 玩法验证阶段（Game Jam 黄金搭档）
- 快速给发行商/投资人展示
- 一人开发，"做出来看看"比"想清楚"快

## 限制

- 不做正式品质的游戏——这是原型阶段
- 浏览器性能有限，不适合 3A 级画面
- 不支持联网多人
- 适合 2D / 轻 3D，不适合复杂的开放世界

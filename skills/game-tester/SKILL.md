# 游戏测试员

> 一人团队最缺测试？让 AI 帮你跑自动化回归测试。

## 能力

- **自动化测试循环**：实现 → 操作 → 暂停 → 截图 → 观察 → 调整
- **Playwright 驱动**：模拟键盘/鼠标操作，自动截图和状态检查
- **多步骤验证**：移动、跳跃、攻击、计分、关卡推进全流程测试
- **控制台错误检查**：自动捕获 JS 运行时错误
- **回归测试**：修改代码后自动重跑全套测试

## 使用方式

```
/game-tester "测试我的 Web 游戏：1.打开游戏 2.按空格开始 3.移动角色收集3个金币 4.验证计分板显示3分 5.碰到敌人验证生命-1"
```

## 工作流

1. 描述测试场景（操作步骤 + 预期结果）
2. AI 生成 Playwright 测试脚本
3. 执行测试 → 截图 → 报告
4. 发现问题 → 修复 → 重测
5. 积累测试用例，形成回归测试套件

## 测试清单模板

```
基础功能：
- [ ] 游戏正常启动，无控制台错误
- [ ] 所有 UI 按钮可点击且有反馈
- [ ] 键盘/鼠标操作响应正常

核心玩法：
- [ ] 角色移动、跳跃、攻击等功能正常
- [ ] 计分系统正确累加
- [ ] 胜负条件正确触发

边界情况：
- [ ] 连续快速操作不崩溃
- [ ] 长时间运行无内存泄漏（观察 5 分钟）
- [ ] 浏览器缩放/窗口调整后正常运行
```

## 适用场景

- Web 游戏 / Three.js 游戏的自动化测试
- 一人开发无 QA 团队的回归测试
- 发布前的冒烟测试

## 限制

- 仅支持 Web 游戏（浏览器环境），不支持 Unity/Unreal 原生游戏
- 不做性能测试（FPS 统计需要引擎内置工具）
- 不做网络游戏的多人同步测试
- 视觉验证依赖截图人工对比，AI 判断可能有误

# 独立黑客策略

> 游戏做完了，没人玩？独立开发者最缺的不是技术，是把产品卖出去的方法。

## 能力

- **定位策略**：找到你的游戏在 Steam / itch.io 上的差异化位置
- **愿望单增长**：Steam 愿望单从 0 到 1000 的实操路径
- **社交媒体矩阵**：Twitter / Reddit / TikTok / B站 的内容策略
- **社区冷启动**：Discord / Reddit 社区的建设和不尬聊的参与方式
- **定价与折扣**：首发定价策略、折扣节奏、捆绑包技巧
- **独立黑客心态**：一次交付持续销售、不追求规模追求利润

## 使用方式

```
/indie-hacker-strategy "我的像素风肉鸽卡牌游戏准备上 Steam，愿望单才 50 个，怎么在 2 个月内做到 500？"
```

## 核心原则

1. **先有受众再做游戏**——开发期间就开始建社区，不要等发布
2. **GIF 比截图强 10 倍**——Steam 商店页第一条就该是动图
3. **Demo 是最大的营销**——Steam Next Fest 的 Demo 是最有效的获客渠道
4. **真实故事即内容**——你的开发幕后、失败记录、设计决策都是营销素材
5. **一次交付持续销售**——不做需要客服和更新的产品，卖完就做下一个

## 时间线建议

```
发布前 6 个月：创建商店页面，开始收集愿望单
发布前 3 个月：参加 Steam Next Fest，发布 Demo
发布前 1 个月：给评测媒体/YouTuber 发 Key
发布前 1 周： 社交媒体密集预热
发布日：       Discord 社区同步庆贺，首日折扣上线
发布后 1 周：  收集评测，快速修复严重 Bug
发布后 1 月：  打折 / 捆绑包 / 长期运营策略
```

## 适用场景

- 第一次发布游戏的独立开发者
- 游戏做好了但"不知道怎么卖"
- 需要建立个人独立开发者品牌

## 限制

- 不帮你写社交媒体帖子（给策略和框架）
- 不做付费广告投放指导
- 不做 IAP/订阅制/免费+广告的变现方案
- 不保证销量——营销是放大器，不是魔法
